# Змейка (Snake Game)

Игра "Змейка" реализована на языке Go с использованием библиотеки [Bubble Tea](https://github.com/charmbracelet/bubbletea) для создания терминального пользовательского интерфейса.

## Особенности

- Классическая игра "Змейка" с современным TUI интерфейсом
- Управление с помощью клавиш W, A, S, D или стрелок
- Автоматическое движение змейки
- Система подсчета очков (по мере роста змейки)
- Поддержка как TUI, так и консольного режимов

## Установка и запуск

### Требования

- Go 1.19 или выше

### Установка

1. Клонируйте репозиторий:
```bash
git clone <ваш_репозиторий>
cd snake
```

2. Установите зависимости:
```bash
go mod download
```

### Запуск

#### В TUI режиме (с графическим интерфейсом в терминале):

```bash
go run main.go
```

#### В консольном режиме (для Codespaces или систем без поддержки TTY):

```bash
go run main_codespaces.go
```

## Управление

- `W` или `Стрелка вверх` - движение вверх
- `S` или `Стрелка вниз` - движение вниз
- `A` или `Стрелка влево` - движение влево
- `D` или `Стрелка вправо` - движение вправо
- `Q` или `Ctrl+C` - выход из игры

## Структура проекта

```
snake/
├── main.go              # Основной файл запуска с TUI
├── main_codespaces.go   # Альтернативный запуск для Codespaces
├── go.mod              # Файл зависимостей Go
├── go.sum              # Суммы зависимостей
├── core/               # Основная логика игры
│   ├── game.go         # Игровая логика
│   ├── snake.go        # Логика змейки
│   ├── field.go        # Игровое поле
│   └── utils.go        # Вспомогательные функции
└── graphics/           # Графический интерфейс
    └── ui.go           # TUI компонент на основе Bubble Tea
```

## Архитектура

Проект разделен на два основных компонента:

1. **Ядро игры (`core/`)**: содержит всю логику игры, включая:
   - Управление змейкой
   - Генерацию яблок
   - Проверку столкновений
   - Рендеринг игрового поля

2. **Графический интерфейс (`graphics/`)**: предоставляет:
   - TUI интерфейс с использованием Bubble Tea
   - Обработку пользовательского ввода
   - Анимацию и обновления экрана
